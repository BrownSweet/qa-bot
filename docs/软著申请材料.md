## 三、软件的简要说明（可直接用于申请表"程序及文档说明"栏）

> 约 480 字，覆盖：开发目的、主要功能、技术特点。可根据实际情况增删。

本软件是一款支持自然语言查询数据库的智能问答系统。针对企业业务人员普遍不具备 SQL 编写能力、难以自主完成数据查询与分析的问题，本软件允许用户接入自定义数据源（MySQL、PostgreSQL、SQLite 数据库及 Excel 文件），通过自然语言直接提出问题，系统自动将其转换为可执行的 SQL 查询语句，执行查询并生成自然语言分析报告，从而降低数据获取与分析的技术门槛，提升企业数据决策效率。

本软件采用前后端分离架构。前端基于 Vue.js 框架、Vite 构建工具及 ElementUI 组件库实现，包含用户认证、数据源配置、多会话管理、问答交互、系统设置等功能模块；后端基于 Python FastAPI 框架实现，采用 SQLAlchemy 完成数据持久化，通过 JSON Web Token（JWT）实现用户身份认证，使用 bcrypt 算法对用户密码进行哈希存储，使用 AES-256 对称加密算法对数据库连接密码及第三方服务密钥进行加密存储。

本软件的核心技术特点包括：（1）自然语言转 SQL（NL2SQL）技术，通过提取目标数据库的表结构信息并结合大语言模型，将用户的自然语言问题自动转换为结构化查询语句；（2）基于 Server-Sent Events（SSE）的流式输出技术，实现问答结果的实时打字机效果展示，并支持用户主动终止生成过程；（3）多类型数据源统一接入能力，将 Excel 电子表格文件动态转换为可查询的关系型数据表，实现与传统数据库的统一查询接口；（4）完善的会话管理机制，支持多会话创建、搜索、置顶与历史消息检索；（5）数据导出功能，支持将问答记录导出为 Excel 或 CSV 格式文件，便于用户离线查阅与分享。

本软件适用于企业数据分析、商业智能报表生成、非技术人员数据自助查询等场景，具有较高的实用性与推广价值。

## 四、软件的主要功能（可作为申请表补充说明或用户手册目录）

1. **用户认证管理**：用户注册、登录、手机验证码找回密码、JWT 令牌鉴权
2. **数据源配置管理**：支持添加/删除/测试 MySQL、PostgreSQL、SQLite、Excel 数据源，密码 AES 加密存储
3. **会话管理**：多会话创建、搜索、改名、置顶、删除
4. **智能问答交互**：自然语言提问、NL2SQL 转换、SQL 执行、结果分析、流式（SSE）输出、Markdown 富文本渲染、消息复制/重试/停止
5. **系统配置管理**：AI 服务（DeepSeek API）密钥配置与连接测试
6. **用户设置**：个人信息维护、密码修改
7. **数据导入**：Excel 文件解析、工作表预览
8. **日志管理**：操作日志与错误日志记录、多条件查询
9. **数据导出**：问答记录导出为 Excel / CSV
10. **消息通知**：系统通知推送、已读标记、删除

## 五、开发目的（如申请表单独有此栏）

为解决非技术人员无法自主编写 SQL 语句、难以从企业数据库中快速获取所需数据这一普遍痛点而开发。通过自然语言处理技术自动生成数据库查询语句并给出分析结论，使业务人员无需掌握专业数据库知识即可完成数据查询与分析工作，提高企业整体的数据利用效率。
